Unmodified copies of the ASSUME-based test specifications of the TLA+ CommunityModules
(https://github.com/tlaplus/CommunityModules, directory `tests/`, commit 057f66c), MIT licensed, see LICENSE.
The `.cfg` files were added here (the upstream build passes its configuration on the command line).

The specs refer to files relative to the repository root (`tests/...`, `build/...`), so they are run with
this directory's layout as the working directory; `test/community.test.ts` does that in a scratch copy.
